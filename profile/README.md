# NextFerret: Arvor Project Division

We are **NextFerret**, the developers and maintainers behind Arvor Linux and its core ecosystem of tools.

Our mission is to build a modern, high-performance Linux ecosystem driven by powerful, specialized utilities:

* **Arvor Linux:** An atomic distribution designed without forced immutability, giving users complete control over their system.
* **napt:** Our advanced, transactional package manager ensuring safe and reliable updates.
* **nlc:** A robust, streamlined chroot manager for isolated environments.
* **nsm:** A powerful snapshot manager built for seamless system recovery and state management.

Explore our projects and join us in shaping the future of Arvor Linux.
